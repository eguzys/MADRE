# GUI.py
A simple and fast running GUI build with [tkinter](https://docs.python.org/3/library/tkinter.html). Components are displayed as dots with colors differentiating whether they are a `MANETNode`, `Jammer` or `User`. A "link" is displayed with a directed link/arrow. Although, in Wifi it is less a link but a possible transmission. The `GUI` if closed can't be reopened. However, it can be minimized and maximized without problem and minimizing will significantly increase the simulation's speed.

::: MANET.GUI
    options:
      show_root_heading: false  # Avoid showing the module name as a header
